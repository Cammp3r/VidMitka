# VidMitka

Мобільний розклад служінь для команди. Клієнтський інтерфейс відкривається на `/`, адмін-панель доступна окремо за адресою `/admin`.


## Як додати сайт на головний екран Android

1. Відкрийте сайт у Google Chrome на телефоні.
2. Натисніть меню з трьома крапками у правому верхньому куті.
3. Оберіть `Додати на головний екран` або `Встановити застосунок`.
4. Підтвердіть назву `VidMitka` і натисніть `Додати`.

Після цього іконка VidMitka з'явиться на головному екрані як звичайний застосунок.

## Як додати сайт на головний екран iPhone

1. Відкрийте сайт у Safari.
2. Натисніть кнопку `Поділитися` внизу екрана.
3. Прокрутіть список дій і натисніть `На початковий екран`.
4. Перевірте назву `VidMitka` і натисніть `Додати`.

На iPhone додавання на головний екран працює саме через Safari.
